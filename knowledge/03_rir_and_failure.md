# RIR and Failure

## Definition

RIR means **Reps In Reserve**.

It estimates how many additional repetitions a person could perform with acceptable technique before reaching muscular failure.

RIR is primarily used to regulate training effort.

---

# 1. RIR Scale

General interpretation:

- 5+ RIR = very easy
- 4 RIR = easy
- 3 RIR = moderately hard
- 2 RIR = hard
- 1 RIR = very hard
- 0 RIR = failure

RIR is an estimate, not a perfectly measurable value.

The user may initially estimate RIR inaccurately.

The agent should improve RIR estimation through repeated training experience and comparison between predicted and actual performance.

---

# 2. Muscular Failure

Muscular failure means the user cannot complete another repetition with acceptable technique under the current conditions.

Failure is not simply:

- Feeling tired
- Feeling a muscle burn
- Feeling uncomfortable
- Becoming out of breath

The relevant question is whether another technically acceptable repetition can be completed.

---

# 3. RIR and Hypertrophy

Muscle growth can occur without taking every set to failure.

Training sets performed reasonably close to failure can provide a strong stimulus.

A practical default for many hypertrophy sets is:

**approximately 1–3 RIR**

This allows sufficiently hard training while limiting unnecessary fatigue.

---

# 4. Why Not Train to Failure Every Set?

Failure increases fatigue.

Excessive failure training can negatively affect:

- Recovery
- Subsequent sets
- Subsequent exercises
- Future workouts
- Running performance
- Training consistency

Failure can therefore be used strategically rather than automatically.

---

# 5. When Failure May Be Useful

Failure may occasionally be appropriate when:

- The exercise is relatively safe.
- Technique can be maintained until failure.
- The user wants to test current capacity.
- The final set is intentionally taken closer to failure.
- The exercise has relatively low systemic fatigue.
- The purpose of the set justifies the additional fatigue.

Failure should be used more cautiously on technically demanding or high-fatigue movements.

---

# 6. When Failure Should Generally Be Avoided

Avoid routine failure when:

- Technique breaks down before muscular failure.
- The exercise is technically demanding.
- The exercise creates substantial joint stress.
- The user is already highly fatigued.
- The user has important training later in the week.
- Lower-body fatigue would interfere with running.
- The user is recovering poorly.

The agent should prioritize useful training over maximum effort.

---

# 7. RIR Targets

Default resistance-training targets can generally be:

### Main compound movements

Approximately:

**2–3 RIR**

Examples:

- Push-ups
- Rows
- Split squats
- RDLs
- Chin-ups
- Pike push-ups

### Smaller/accessory movements

Approximately:

**1–3 RIR**

Examples:

- Face pulls
- Lateral raises
- Calf raises
- Core exercises

These are defaults, not immutable rules.

The target can change depending on the user's current phase and recovery.

---

# 8. RIR and Repetition Ranges

RIR must be interpreted together with the repetition target.

Example:

3 × 8–15 @ 2 RIR

A set of:

15 reps @ 2 RIR

is not equivalent to:

15 reps @ 5 RIR

The first is near the intended training difficulty.

The second is likely too easy for the intended stimulus.

---

# 9. RIR Accuracy

RIR is subjective.

A user may believe they have:

2 RIR

but actually have:

4 RIR

or:

0 RIR

The agent should therefore avoid treating reported RIR as perfect objective data.

Useful ways to improve accuracy include occasional controlled sets closer to failure and comparing the predicted RIR with actual remaining capacity.

Failure testing should not become routine.

---

# 10. RIR and Technique

RIR should be based on **acceptable repetitions**, not ugly repetitions.

If the user can technically complete another repetition only by:

- Losing body position
- Using excessive momentum
- Shortening range of motion
- Changing the movement pattern

that repetition should generally not count as a clean available rep.

Example:

If a user completes 10 clean push-ups and the 11th would require major form breakdown, the useful estimate may be approximately:

**10 reps + 0 RIR**

rather than counting several poor repetitions afterward.

---

# 11. RIR and Progressive Overload

RIR helps determine whether performance improvements are genuine.

Example:

Session 1:
10 reps @ 2 RIR

Session 2:
12 reps @ 2 RIR

This is meaningful progression.

But:

Session 1:
10 reps @ 2 RIR

Session 2:
15 reps @ 5 RIR

is not necessarily a meaningful increase in training stimulus.

The agent should consider both performance and effort.

---

# 12. RIR and Different Exercises

RIR is easier to estimate for some movements than others.

It may be relatively straightforward for:

- Push-ups
- Rows
- Curls
- Lateral raises

It may be harder for:

- Complex compound movements
- Exercises with balance limitations
- Movements limited by cardiovascular fatigue
- Exercises where technique fails before the target muscle

The agent should account for this uncertainty.

---

# 13. RIR and Running

RIR is primarily a resistance-training concept.

Running should generally use other measures such as:

- RPE
- Pace
- Heart rate
- Talk test
- Session difficulty

Do not force the RIR framework onto running.

For example:

An easy run should be evaluated based on aerobic effort and recoverability rather than "2 RIR."

---

# 14. RIR During Different Phases

### Normal training

Most working sets:

**1–3 RIR**

### High-fatigue period

Training may temporarily move farther from failure:

**2–4+ RIR**

### Deload/recovery period

Effort may be reduced further.

### Testing

Some selected exercises may occasionally approach failure to establish capacity.

Testing should not replace normal training.

---

# 15. RIR and Concurrent Training

Because the user runs three times per week, resistance-training effort must be considered alongside running fatigue.

Example:

If lower-body training is normally performed at approximately 2 RIR, but the user has accumulated substantial running fatigue, the agent may temporarily use approximately 3 RIR rather than forcing the usual effort.

This can preserve training consistency while reducing unnecessary fatigue.

---

# 16. Failure Is Not the Goal

The goal of resistance training is adaptation.

Failure is simply one point on the effort spectrum.

The agent should never treat:

"closer to failure"

as automatically meaning:

"better workout."

The correct question is:

**Was the training stimulus sufficient for the goal at an acceptable fatigue cost?**

---

# 17. Decision Rules

### If the user is consistently finishing sets with much higher RIR than target

The exercise may be too easy.

Consider progression.

### If the user reaches target repetitions at the intended RIR

Maintain or progress according to the progression rules.

### If the user reaches failure much earlier than expected

Reduce difficulty, resistance, or target repetitions.

### If the user repeatedly reaches failure despite a higher-RIR target

Investigate load selection, technique, fatigue, and recovery.

### If fatigue is high

Move the target farther from failure rather than forcing normal effort.

### If pain occurs

Do not interpret pain as low RIR or normal training effort.

Pain requires separate assessment.

---

# 18. Core Principle

RIR is a tool for controlling training effort.

It should be used to keep training:

- Hard enough to stimulate adaptation
- Controlled enough to recover
- Consistent enough to progress

The objective is not to reach failure.

**The objective is to train close enough to failure to create a useful stimulus without accumulating unnecessary fatigue.**
