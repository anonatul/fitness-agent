# Exercise Selection

## Purpose

Exercise selection determines which movements are used to create the required training stimulus.

The agent should select exercises based on the user's goal, ability, equipment, progression potential, recovery demands, and comfort.

The goal is not to collect as many exercises as possible.

The goal is to build a small set of effective, repeatable movements that can be progressed over time.

---

# 1. Movement Patterns

The training system should cover the major movement patterns.

### Upper body

- Horizontal push
- Horizontal pull
- Vertical push
- Vertical pull

### Lower body

- Squat
- Single-leg/lunge
- Hip hinge
- Knee flexion
- Calf work

### Core

- Anti-extension
- Anti-rotation
- Lateral stability
- Controlled trunk movement

Not every movement pattern must appear in every workout.

The weekly program should provide appropriate coverage.

---

# 2. Exercise Selection Criteria

An exercise should generally be considered useful when it:

- Trains the intended muscles effectively.
- Can be performed with acceptable technique.
- Provides meaningful resistance.
- Has a useful range of motion.
- Can be progressed.
- Fits available equipment.
- Does not create unnecessary joint or tendon irritation.
- Has an acceptable fatigue cost.
- Fits the user's schedule.
- Can be repeated consistently.

---

# 3. Progression Potential

Progression potential is especially important.

An exercise that is effective today but impossible to progress should not necessarily remain a long-term primary movement.

Useful progression methods include:

- Adding resistance
- Adding repetitions
- Increasing range of motion
- Reducing assistance
- Increasing exercise difficulty
- Improving execution

The agent should prefer exercises where progression can be measured.

---

# 4. Skill Requirement

Some exercises require substantial technical skill.

The agent should distinguish:

### Skill-limited exercises

Performance may improve substantially because the user becomes better at the movement.

### Muscle-limited exercises

Performance is more directly limited by muscular capacity.

Both can be useful.

However, the agent should not interpret skill improvement as pure muscle growth.

---

# 5. Stability and Balance

Some movements are limited by balance or stability rather than the target muscle.

Examples include certain:

- Single-leg exercises
- Advanced bodyweight movements
- Unstable variations

The agent should use stable variations when stability is preventing sufficient muscular loading.

Instability is not automatically beneficial.

---

# 6. Exercise Complexity

Advanced does not mean better.

A simple exercise that:

- Produces a good stimulus
- Can be performed safely
- Can be progressed
- Can be repeated consistently

is often preferable to a complicated movement.

Exercise difficulty should match the user's current ability.

---

# 7. User Equipment

The user's current equipment includes:

- Resistance bands
- Door anchor
- Pull-up bar
- Bench/chair
- Loadable backpack

The agent should prioritize exercises that can be effectively performed using these tools.

Gym equipment should not be assumed unless the user says it is available.

---

# 8. Horizontal Push

Primary examples:

- Incline push-up
- Standard push-up
- Band-resisted push-up
- Feet-elevated push-up
- Other progressively harder push-up variations

The progression should be based on the user's actual ability.

The agent should not force standard push-ups if the user cannot perform them with good technique.

---

# 9. Horizontal Pull

Primary examples:

- Resistance-band row
- Backpack row
- Other stable rowing variations

The setup should remain reasonably consistent so progression can be tracked.

Band setup should be recorded when useful.

---

# 10. Vertical Push

Possible exercises:

- Pike push-up
- Band overhead press
- Other appropriate overhead pressing variations

The agent should choose the variation that provides sufficient challenge while maintaining acceptable technique.

---

# 11. Vertical Pull

Possible exercises:

- Band-assisted chin-up
- Band-assisted pull-up
- Band lat pulldown
- Other appropriate vertical pulling variations

For a beginner who cannot perform an unassisted pull-up or chin-up, assisted variations should be used rather than repeatedly attempting failed repetitions.

Progression can occur by gradually reducing assistance.

---

# 12. Squat Pattern

Possible exercises:

- Bodyweight squat
- Backpack squat
- Split squat
- Bulgarian split squat

The appropriate variation depends on:

- Strength
- Balance
- Range of motion
- Equipment
- Running fatigue

---

# 13. Single-Leg Training

Single-leg movements are useful for:

- Lower-body strength
- Coordination
- Stability
- Addressing side-to-side differences

Examples:

- Reverse lunge
- Split squat
- Bulgarian split squat
- Step-up

Small differences between sides are common.

The agent should not automatically assume a serious problem from a minor performance difference.

However, large or persistent asymmetries, especially when associated with pain, should be investigated.

---

# 14. Hip Hinge

Hip-hinge exercises train the posterior chain.

Examples:

- Backpack Romanian deadlift
- Band Romanian deadlift
- Band good morning
- Hip bridge
- Single-leg hinge variations

The agent should prioritize controlled hip movement and appropriate loading.

---

# 15. Knee Flexion

Knee-flexion work can target the hamstrings through a different function than hip-hinge movements.

Possible exercises include:

- Band leg curl
- Sliding leg curl
- Nordic progression
- Other appropriate knee-flexion variations

The exercise should match the user's current strength and equipment.

---

# 16. Calves

Possible exercises:

- Single-leg calf raise
- Two-leg calf raise
- Loaded calf raise
- Bent-knee calf raise

Running already provides repeated calf loading.

Therefore, calf training volume should be considered alongside running volume.

---

# 17. Core

Core training should not be reduced to endless sit-ups.

Useful categories include:

### Anti-extension

Examples:

- Plank
- Dead bug
- Ab wheel progression when appropriate

### Anti-rotation

Examples:

- Pallof press

### Lateral stability

Examples:

- Side plank
- Suitcase carry when equipment allows

The agent should select core exercises based on the movement requirement and user's ability.

---

# 18. Range of Motion

Use a useful range of motion that the user can control.

Do not deliberately shorten movement simply to increase repetitions.

However, range of motion may be modified when:

- Mobility is limiting the movement.
- Equipment restricts the movement.
- A specific range causes pain.
- A partial range is intentionally used as a progression method.

Range of motion should be tracked when it meaningfully affects exercise difficulty.

---

# 19. Exercise Substitution

The agent should be able to substitute exercises without destroying the structure of the program.

Substitute based on movement pattern and training objective.

Example:

```text
Bulgarian split squat
→ reverse lunge
→ step-up
```

The replacement should provide a reasonably similar training purpose.

Substitution may be necessary because of:

- Equipment
- Pain
- Fatigue
- Space
- Time
- User preference

---

# 20. Pain and Exercise Selection

Pain is not simply a signal that an exercise is "working."

If an exercise causes concerning or persistent pain:

1. Stop or modify the movement.
2. Identify whether technique/setup may be contributing.
3. Consider a less provocative variation.
4. Monitor the response.
5. Seek appropriate professional assessment when necessary.

The agent must not encourage the user to train through significant pain simply to preserve the program.

---

# 21. Fatigue Cost

Two exercises can train similar muscles while creating different amounts of fatigue.

The agent should consider:

- Local muscular fatigue
- Systemic fatigue
- Stability demands
- Technical demands
- Recovery cost
- Effect on subsequent training

Exercise selection should account for the entire weekly program.

---

# 22. Exercise Redundancy

The agent should avoid unnecessary duplication.

For example, a program does not necessarily need many variations of the same movement pattern simply because they target similar muscles.

Additional exercises should have a clear purpose.

Possible purposes include:

- Additional volume
- Different muscle emphasis
- Different resistance profile
- Skill development
- Addressing a limitation
- Reducing repetitive stress
- Improving variety when useful

---

# 23. Exercise Rotation

Exercises do not need to change constantly.

Keeping movements stable for sufficient time makes progression easier to measure.

The agent should rotate an exercise when there is a meaningful reason, such as:

- Persistent pain
- Stagnation
- Equipment change
- User preference
- A new training phase
- Need for a different stimulus
- Excessive repetition or boredom

Novelty alone is not a reason to change an effective exercise.

---

# 24. Exercise Selection and Running

Because the user runs three times per week, lower-body exercise selection should account for running.

If running load is high, the agent may favor exercises that provide useful strength stimulus without unnecessarily increasing lower-body fatigue.

For example:

- Maintain reasonable lower-body volume.
- Avoid excessive redundant leg exercises.
- Monitor calf and shin stress.
- Avoid placing unnecessarily demanding lower-body sessions immediately before important running sessions when possible.

---

# 25. Exercise Selection Hierarchy

When selecting an exercise, prioritize:

1. Safety
2. Training goal
3. Ability to perform the movement
4. Progression potential
5. Recoverability
6. Equipment availability
7. User preference
8. Variety

Do not sacrifice a useful exercise merely for novelty.

---

# 26. Decision Rules

### If the exercise provides a good stimulus + progression is occurring + no pain:

Keep it.

### If the exercise is too easy:

Increase difficulty or resistance.

### If the exercise is too difficult:

Use an easier variation or assistance.

### If technique consistently breaks down:

Reduce difficulty.

### If an exercise causes persistent pain:

Modify or replace it.

### If an exercise cannot be progressed:

Consider whether another variation provides better long-term progression.

### If the user dislikes an otherwise effective exercise:

Consider an alternative movement pattern or variation that achieves a similar purpose.

---

# 27. Core Principle

Exercise selection is not about finding the "perfect" exercise.

The goal is to select movements that are:

**effective, measurable, safe, recoverable, and progressively overloadable.**

A small number of well-chosen exercises performed consistently is more useful than constantly changing exercises without a clear reason.
