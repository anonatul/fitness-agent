# Concurrent Training

## Purpose

Concurrent training means developing strength/muscle and endurance within
the same overall training system.

For this user, concurrent training means combining:

- Strength training
- Running
- Body composition improvement
- General athleticism

The primary priority is:

**Strength and muscle > leaner body composition > running performance**

Running remains an important long-term capability.

The agent must balance these goals rather than treating them as separate
programs.

---

# 1. Concurrent Training Does Not Automatically Kill Muscle Gain

Running and strength training can coexist effectively.

The main problem is not simply doing both.

Problems usually arise when total training stress becomes too high or
when sessions are poorly scheduled.

Potential causes include:

- Excessive running volume
- Too many hard running sessions
- Excessive lower-body strength volume
- Poor recovery
- Insufficient nutrition
- Poor sleep
- Rapid increases in training load

The agent should manage the total stress rather than unnecessarily
eliminating running.

---

# 2. Training Priority

When strength and endurance goals conflict, the agent should use the
current phase and primary objective to determine which quality receives
more training resources.

For the user's current priorities:

1. Strength/muscle
2. Body composition
3. Running fitness
4. Long-term endurance capability

This does not mean running should be ignored.

It means running should support overall fitness without unnecessarily
interfering with strength progress.

---

# 3. Weekly Training Structure

The current default structure is:

- 3 strength sessions
- 3 running sessions
- 1 recovery/rest-oriented day

Running consists of:

- Easy aerobic run
- Quality run
- Long easy run

Strength consists of:

- Full-body training
- Repeated exposure to major movement patterns
- Progressive overload

This is a starting structure, not a permanent rule.

---

# 4. Strength Sessions

Strength sessions should cover the major movement patterns over the week:

- Horizontal push
- Horizontal pull
- Vertical push
- Vertical pull
- Squat
- Single-leg movement
- Hip hinge
- Calves
- Core

Not every session needs every movement.

The agent should distribute exercises across the week according to
recovery and progression needs.

---

# 5. Running Sessions

### Easy Run

Purpose:

- Aerobic development
- Recovery-friendly conditioning
- Running economy
- Building consistent mileage

The effort should remain controlled.

### Quality Run

Purpose:

- Improve running performance
- Develop speed or threshold-related fitness
- Provide a controlled higher-intensity stimulus

Examples:

- Intervals
- Tempo/threshold work
- Controlled hills

### Long Easy Run

Purpose:

- Aerobic endurance
- Muscular endurance
- Gradual preparation for longer-distance capability

The long run should generally remain easy.

---

# 6. Why Easy Running Matters

Not every run should be hard.

If all three weekly runs become demanding, total fatigue can rise
quickly.

Easy running allows the user to accumulate aerobic work while keeping
recovery demands relatively manageable.

The agent should protect easy days from becoming accidental hard days.

---

# 7. Hard Training Distribution

Hard strength and hard running sessions both consume recovery capacity.

The system should avoid unnecessarily stacking high-fatigue sessions.

Example of poor distribution:

Hard lower-body strength
→ hard intervals
→ hard lower-body strength
→ long hard run

This creates excessive lower-body stress.

A better structure separates demanding sessions where practical.

---

# 8. Lower-Body Interference

The legs are shared between running and strength training.

Lower-body strength training can temporarily reduce running performance.

Hard running can temporarily reduce lower-body strength performance.

This does not mean the two adaptations are incompatible.

It means scheduling and recovery matter.

---

# 9. Session Spacing

When possible, provide sufficient separation between demanding sessions
that stress the same tissues and movement patterns.

Examples:

- Hard lower-body strength and hard running should not be unnecessarily
  stacked.
- An easy run can often fit between strength sessions.
- Upper-body-focused strength creates less direct interference with
  running.

The agent should consider the actual workload rather than applying a
fixed number of hours to every situation.

---

# 10. Same-Day Training

Strength and running can sometimes occur on the same day.

When both are required on the same day, the priority determines the
order.

For a strength-priority phase:

**Strength generally comes before running**

when the sessions are performed close together.

However, scheduling convenience and recovery may justify separating them.

The agent should not force same-day training when separate scheduling is
practical.

---

# 11. Strength Before Running

If strength is the primary objective, performing strength before a
hard running session may protect strength quality.

However, fatigue from strength training can reduce running performance.

Therefore, hard lower-body strength should not automatically be placed
immediately before important quality running.

---

# 12. Running Before Strength

Running before strength may be appropriate when running is the priority
or when the run is easy.

An easy run generally creates less interference than a hard interval
session.

The agent should consider the intended quality of both sessions.

---

# 13. Lower-Body Volume

Lower-body strength volume must account for running.

The user does not need to maximize lower-body lifting volume while also
running three times per week.

If running volume increases significantly, the agent may temporarily
reduce unnecessary lower-body strength volume.

The goal is to maintain productive strength stimulus without creating
excessive fatigue.

---

# 14. Upper-Body Training

Upper-body training usually has less direct interference with running.

Therefore, upper-body volume can often remain more stable even when
running load changes.

The agent should still consider total systemic fatigue.

---

# 15. Running Volume Progression

Running volume should increase gradually.

The agent should avoid automatically applying a rigid percentage increase
every week.

Instead consider:

- Current mileage
- Recent mileage
- Longest recent run
- Recovery
- Pain
- Running performance
- User availability

A sudden increase in both mileage and intensity is especially
unnecessary.

---

# 16. Long Run Progression

The long run should progress according to the user's current endurance
and recovery.

The agent should not increase long-run distance aggressively simply
because the user completed the previous run successfully.

Successful completion does not automatically mean the next run should be
much longer.

---

# 17. Quality Running

Quality running should remain purposeful.

The agent should not add intervals merely to make training harder.

Possible progression methods include:

- More repetitions
- Longer work intervals
- Slightly faster pace
- Shorter recovery
- More total quality time

Only one major variable should usually change at a time.

---

# 18. Strength Progression During Concurrent Training

Strength progression should continue whenever recovery allows.

Progression can occur through:

- More repetitions
- More resistance
- More difficult variation
- Better range of motion
- Additional sets
- Better execution

The agent should not force progression when running load or fatigue is
already high.

---

# 19. Body Composition

Concurrent training can support body composition improvement.

However, training does not override energy balance.

If the user wants to lose body fat:

- Maintain a reasonable calorie deficit.
- Keep protein high.
- Continue resistance training.
- Maintain manageable running volume.
- Avoid aggressive dieting that compromises recovery.

The agent should prioritize preserving muscle while reducing body fat.

---

# 20. Nutrition for Concurrent Training

Concurrent training increases the importance of adequate nutrition.

Protein supports muscle retention and growth.

Carbohydrates support running and higher-volume training.

Total energy intake affects:

- Recovery
- Performance
- Body composition
- Training quality

The agent should not recommend severe restriction simply to accelerate
fat loss.

---

# 21. Fatigue Management

The agent should evaluate total weekly stress.

Sources include:

- Strength volume
- Running mileage
- Running intensity
- Long-run duration
- Daily activity
- Sleep
- Nutrition
- Life stress

Training load should be considered as a system.

---

# 22. When Strength Progresses but Running Stalls

Possible causes include:

- Insufficient running-specific work
- Excessive lower-body fatigue
- Poor running distribution
- Insufficient aerobic development
- Poor recovery
- Inappropriate intensity

The agent should investigate before changing the entire program.

---

# 23. When Running Progresses but Strength Stalls

Possible causes include:

- Excessive running load
- Insufficient strength volume
- Poor strength progression
- Insufficient calories
- Insufficient protein
- Poor recovery

If strength/muscle is the current priority, the agent should consider
reducing unnecessary endurance stress before abandoning strength work.

---

# 24. When Both Stall

If both strength and running performance decline, investigate:

- Recovery
- Sleep
- Nutrition
- Recent training load
- Stress
- Illness
- Pain
- Program adherence

Do not automatically add more training.

More training is often the wrong response to poor adaptation.

---

# 25. Concurrent Training During Different Phases

Concurrent training does not require equal emphasis forever.

A phase may emphasize:

### Strength emphasis

- Higher strength/muscle priority
- Running maintained at useful volume
- Limited high-intensity running

### Endurance emphasis

- Running volume or quality increases
- Strength maintained with efficient volume
- Lower-body strength fatigue managed carefully

### Consolidation

- Both qualities maintained
- Moderate training stress
- Recovery prioritized

The emphasis can change over time.

---

# 26. Half Marathon Capability

The user's long-term goal is to become capable of comfortably running
21.1 km.

This is a capability goal, not a permanent race-preparation phase.

The system should first build:

- Consistent running
- Aerobic base
- Long-run tolerance
- Recovery capacity
- Gradual distance progression

Once the user becomes capable of the distance, running volume can later
be reduced while maintaining enough endurance to preserve the capability.

A future endurance-focused phase can rebuild it when desired.

---

# 27. Missed Sessions

If a session is missed:

Do not automatically cram it into the next day.

Instead evaluate:

- What was missed?
- What is scheduled next?
- Current fatigue
- Importance of the missed session
- Recent training load
- User availability

The agent should recalculate the schedule.

---

# 28. Changing Running Load

If running increases substantially:

The agent should consider reducing unnecessary lower-body training
volume.

If running decreases substantially:

The agent may have more recovery capacity available for strength
progression.

The system should adapt both sides together.

---

# 29. Pain and Concurrent Training

Pain that appears during running or strength training should influence
the entire weekly plan.

For example:

Persistent lower-leg pain may require reducing running stress rather
than simply changing one strength exercise.

The agent must not diagnose injuries.

Persistent, severe, worsening, or function-limiting pain should be
evaluated by an appropriate healthcare professional.

---

# 30. Decision Rules

### If strength is progressing + running is progressing:

Continue current balance.

### If strength is progressing + running is stable:

Maintain running or make small endurance adjustments.

### If strength is declining + running load recently increased:

Consider reducing unnecessary running stress.

### If running is declining + lower-body fatigue is high:

Review lower-body strength volume and session spacing.

### If both are declining:

Investigate total recovery and training load before adding work.

### If body composition improves + performance remains stable:

Continue the current approach.

### If body composition improves + performance deteriorates:

The calorie deficit or total training stress may be too aggressive.

### If the user enters an endurance-focused phase:

Increase running emphasis while maintaining enough strength stimulus.

---

# 31. Core Principle

Concurrent training is a resource-allocation problem.

The goal is not to maximize every quality simultaneously.

The goal is to give the highest-priority adaptation enough stimulus while
keeping the other qualities at a useful level and maintaining recoverable
total training stress.

**Train everything. Emphasize what matters most right now.**
