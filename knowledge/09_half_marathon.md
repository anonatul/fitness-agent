# Half Marathon

## Purpose

The user's long-term running capability goal is to comfortably run
**21.1 km**.

This is a capability goal, not a permanent race-preparation goal.

The agent should build the underlying endurance gradually and only use a
specific half-marathon-focused phase when it is actually necessary.

The broader fitness priorities remain:

**Strength/muscle > body composition > running performance**

---

# 1. What the Goal Means

"Half-marathon capable" means the user can complete approximately
21.1 km at a controlled effort without the distance becoming an
unmanageable physical challenge.

It does not require:

- Racing
- A specific finishing time
- Maximum effort
- Permanent high running mileage
- Permanent endurance specialization

The target is durable capability.

---

# 2. Required Development

The agent should develop the following qualities:

- Consistent running
- Aerobic fitness
- Long-run tolerance
- Muscular endurance
- Running economy
- Recovery capacity
- Ability to tolerate progressively longer sessions
- Confidence at longer distances

The long run is especially important because the user must eventually
tolerate prolonged continuous running.

---

# 3. Development Sequence

A useful progression is:

**Consistency**
→ **Aerobic base**
→ **Regular long runs**
→ **Longer long runs**
→ **Improved endurance**
→ **Specific preparation**
→ **21.1 km capability**

The exact duration of each stage should depend on the user's response.

---

# 4. No Fixed Timeline

The agent must not promise that the user will be ready for 21.1 km in a
specific number of weeks without sufficient data.

Readiness depends on:

- Current running volume
- Longest recent run
- Training consistency
- Recovery
- Pain
- Running performance
- Strength training load
- Life stress

The system should progress according to adaptation rather than an
arbitrary calendar.

---

# 5. Base Phase

Before substantial long-run progression, establish consistency.

Primary objectives:

- Run regularly
- Keep most running easy
- Build tolerance to repeated weekly running
- Establish recovery habits
- Monitor lower-leg response

The user should not chase distance immediately.

---

# 6. Long-Run Development

The long run is the main tool for developing distance tolerance.

Progress should be gradual.

The agent may increase:

- Distance
- Duration
- Frequency

But should avoid increasing multiple major stressors aggressively at the
same time.

---

# 7. Long Run Should Stay Mostly Easy

The long run does not need to become a race simulation.

A controlled effort allows the user to accumulate endurance while keeping
recovery manageable.

The agent should generally prioritize:

**Duration + consistency > speed**

during long-run development.

---

# 8. Long-Run Progression

A successful long run does not automatically require a large increase in
the next long run.

The agent should evaluate:

- How difficult the run felt
- Recovery afterward
- Any pain
- Sleep after the session
- Performance in subsequent sessions
- Total weekly training load

If recovery is poor, progression should pause or reverse.

---

# 9. Running Frequency

Three weekly runs are currently a useful default:

1. Easy run
2. Quality run
3. Long easy run

Frequency can change if necessary.

Increasing to more runs is not automatically better.

The agent should only increase frequency when the additional exposure
provides a useful benefit without compromising strength and recovery.

---

# 10. Quality Running During Half-Marathon Development

Quality running can support:

- Aerobic capacity
- Threshold-related fitness
- Running economy
- Ability to sustain faster controlled efforts

Examples include:

- Tempo running
- Threshold intervals
- Controlled intervals
- Hills

Quality work should support the long-term objective rather than becoming
a separate race.

---

# 11. Strength During Half-Marathon Development

Strength training remains important.

It supports the user's broader goal of maintaining or building strength
and muscle while improving endurance.

During an endurance-focused phase, strength volume may be reduced if
necessary, but resistance training should generally remain present.

The agent should preserve useful strength stimulus rather than removing
strength training completely.

---

# 12. Lower-Body Strength

Lower-body strength training must be coordinated with long-run
progression.

When long-run volume increases significantly, unnecessary lower-body
volume may need to decrease.

The objective is:

**Enough strength stimulus + enough endurance stimulus + recoverable total
load**

---

# 13. Upper-Body Strength

Upper-body training can generally remain more stable during endurance
development because it creates less direct running interference.

However, whole-body fatigue still matters.

---

# 14. Half-Marathon Readiness

Before attempting 21.1 km, the agent should evaluate:

- Consistent recent running
- Sufficient long-run experience
- No concerning pain
- Stable recovery
- Ability to tolerate longer easy runs
- Reasonable weekly training consistency

The user should not attempt the distance simply because the calendar says
it is time.

---

# 15. Readiness Is Not a Single Number

The agent should avoid creating a fake "half-marathon readiness score"
unless it has a useful validated purpose.

Readiness should instead be evaluated from multiple inputs:

- Recent long runs
- Weekly volume
- RPE
- Recovery
- Pain
- Consistency
- Performance

---

# 16. First 21.1 km Attempt

The first attempt should be treated differently from a race.

Primary objective:

**Complete the distance under control.**

Avoid:

- Aggressive starting pace
- Racing the clock
- Starting faster than training pace
- Turning the final kilometers into a maximal effort

The first attempt provides valuable information about actual endurance.

---

# 17. Pacing

For a capability-focused attempt, conservative pacing is preferred.

The user should begin at an effort that feels sustainable.

A common mistake is starting too quickly because the early kilometers
feel easy.

The agent should prioritize:

**Controlled beginning → sustainable middle → optional progression**

rather than:

**Fast beginning → fatigue → survival**

---

# 18. Fueling and Hydration

Longer running sessions increase the importance of hydration and
carbohydrate availability.

For longer sessions, the agent can consider:

- Pre-run meal timing
- Carbohydrate intake
- Fluids
- Electrolytes when appropriate
- Individual tolerance

The agent should avoid introducing unfamiliar nutrition strategies
during an important long run.

---

# 19. Recovery After Long Runs

Long runs can create substantial fatigue.

After a demanding long run, the agent should evaluate:

- Leg soreness
- Energy
- Sleep
- Appetite
- Running performance
- Strength performance
- Pain

The next training session may need to be easier.

---

# 20. Missed Long Runs

If the user misses a long run:

Do not automatically double the next long run.

Instead:

1. Assess the current training state.
2. Determine how much endurance work was missed.
3. Check recovery.
4. Resume from the most appropriate recent workload.
5. Progress gradually.

One missed run does not destroy endurance development.

---

# 21. Breaks in Training

After a significant break, the user should not immediately return to
their previous long-run distance.

Previous cardiovascular fitness may remain partially present while
tolerance to training load has decreased.

The agent should rebuild gradually.

---

# 22. Pain During Long-Run Development

Long-distance progression increases repetitive loading.

The agent should monitor:

- Shin discomfort
- Foot pain
- Knee pain
- Hip pain
- Achilles/tendon discomfort
- Persistent muscle pain
- Changes in running mechanics

Pain that is severe, worsening, persistent, or function-limiting should
not be ignored.

The agent must not diagnose injuries.

Appropriate professional assessment should be recommended when warranted.

---

# 23. Half Marathon and Body Composition

The user also wants to become leaner.

A moderate calorie deficit may be compatible with endurance development.

However, aggressive dieting can compromise:

- Recovery
- Running performance
- Strength
- Training consistency

When endurance demands increase, the agent should prioritize adequate
fueling rather than chasing rapid weight loss.

---

# 24. Half Marathon and Strength Priority

When strength/muscle is the primary objective:

- Keep running useful but controlled.
- Avoid unnecessary mileage.
- Maintain the long-term endurance trajectory slowly.

When half-marathon capability becomes the active priority:

- Increase endurance-specific training.
- Maintain strength with efficient volume.
- Allocate more recovery resources to running.

The system can later shift back toward strength.

---

# 25. Capability Maintenance

After the user can comfortably run 21.1 km, there is no requirement to
continue increasing running volume indefinitely.

The user can shift toward:

- Strength emphasis
- General fitness
- Lower running volume
- Periodic longer runs

The goal becomes maintaining enough endurance to preserve the capability.

---

# 26. Returning to Half-Marathon Focus

If the user later wants to improve endurance again, the agent can
temporarily increase running emphasis.

The system can rebuild:

- Long-run distance
- Weekly volume
- Quality running
- Specific endurance

The previous capability provides useful history but does not guarantee
that the user can immediately resume previous mileage.

---

# 27. Phase Structure

A possible long-term structure is:

### Phase 1 — Base

Build consistent running.

### Phase 2 — Endurance Development

Gradually extend long-run capacity.

### Phase 3 — Half-Marathon Capability

Develop enough endurance to comfortably complete 21.1 km.

### Phase 4 — Maintenance

Reduce running emphasis while maintaining useful endurance.

### Phase 5 — Strength Re-emphasis

Return more recovery resources to strength and muscle development.

These phases are flexible.

The agent should not force a phase transition simply because a certain
number of weeks has passed.

---

# 28. Decision Rules

### If running consistency is poor:

Do not increase long-run distance aggressively.

### If long runs are comfortable + recovery is good:

Progress gradually.

### If long-run recovery is poor:

Maintain or reduce the workload.

### If pain appears or worsens:

Stop progression and evaluate the issue.

### If strength is suffering significantly:

Reduce unnecessary endurance stress.

### If endurance is the active priority:

Increase running emphasis while maintaining strength efficiently.

### If 21.1 km capability is achieved:

Consider shifting toward maintenance or another primary goal.

---

# 29. Core Principle

The half marathon is a **capability milestone**, not the entire training
identity.

The system should build the endurance required to run 21.1 km while
preserving the user's strength, muscle, recovery, and general athleticism.

**Build the capability. Prove it. Maintain it. Then reallocate training
toward the next priority.**
