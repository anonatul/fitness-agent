# Periodization

## Purpose

Periodization is the deliberate organization of training emphasis over
time.

The user's training system should not remain equally focused on every
quality forever.

The agent should change training emphasis according to:

- Current goals
- Progress
- Recovery
- Training history
- Performance
- Life constraints
- Long-term objectives

Periodization should create direction without becoming a rigid calendar.

---

# 1. Why Periodization Exists

Training adaptations compete for limited resources:

- Time
- Recovery
- Energy
- Attention
- Training capacity

Trying to maximize strength, hypertrophy, running performance, and every
other quality simultaneously is inefficient.

Periodization allows the system to emphasize one priority while
maintaining useful levels of other qualities.

---

# 2. User's Long-Term Priority

The current default hierarchy is:

1. Strength and muscle
2. Leaner body composition
3. Running fitness
4. Long-term endurance capability
5. General athleticism

This hierarchy can change when the user deliberately changes goals.

---

# 3. Training Phases

A phase is a period where training has a relatively clear emphasis.

Possible phases include:

### Strength/Hypertrophy Emphasis

Primary goal:

- Increase strength
- Build muscle

Running remains present but is controlled.

### Endurance Emphasis

Primary goal:

- Improve aerobic fitness
- Increase running capacity
- Develop long-run ability

Strength is maintained with efficient training.

### Body-Composition Emphasis

Primary goal:

- Reduce body fat
- Preserve muscle
- Maintain performance

Training remains productive while nutrition creates the main body-composition
change.

### Consolidation/Maintenance

Primary goal:

- Maintain adaptations
- Recover
- Stabilize performance
- Prepare for the next emphasis

---

# 4. Phases Are Not Completely Separate

A strength-focused phase still includes running.

An endurance-focused phase still includes strength.

A body-composition phase still includes progressive resistance training.

The difference is the allocation of training resources.

---

# 5. Phase Duration

There should be no universal rule such as:

"Every phase must last exactly 4 weeks."

Useful phase duration depends on:

- Goal
- Adaptation
- Fatigue
- Progress
- Schedule
- Motivation
- Upcoming events

The agent should evaluate whether the current emphasis is still useful.

---

# 6. Starting a Phase

Before entering a new phase, the agent should establish:

- Primary objective
- Secondary objectives
- Current training status
- Recent training history
- Recovery state
- Current performance
- Available equipment
- Schedule constraints
- Relevant limitations

The phase should have a clear reason for existing.

---

# 7. Phase Objectives

Each phase should define measurable outcomes.

Examples:

### Strength phase

- Increase push-up variation performance
- Increase row resistance
- Improve split squat strength
- Build muscle

### Endurance phase

- Increase long-run tolerance
- Improve easy-run efficiency
- Improve quality-run performance
- Progress toward 21.1 km capability

### Body-composition phase

- Reduce waist measurement
- Maintain or improve strength
- Maintain running ability

Objectives should be realistic and compatible.

---

# 8. Training Emphasis

The primary quality receives more resources.

For example:

### Strength emphasis

- Higher strength volume
- More progression attention
- More recovery resources allocated to lifting
- Running kept manageable

### Endurance emphasis

- More running-specific progression
- Long run receives greater attention
- Strength volume becomes more efficient
- Recovery is allocated toward endurance

---

# 9. Maintenance

Secondary qualities do not necessarily need the same training volume
required to improve them.

Once an adaptation is established, less training may be sufficient to
maintain it than was required to build it.

Therefore, during an endurance-focused phase, strength volume may be
reduced while preserving useful resistance training.

Similarly, during a strength-focused phase, running volume can be reduced
while maintaining aerobic fitness.

---

# 10. Progressive Overload Within a Phase

Periodization does not replace progressive overload.

Within each phase, the agent should still attempt to improve the targeted
quality through appropriate progression.

For strength:

- More repetitions
- More resistance
- Harder variation
- More sets when justified
- Better execution

For running:

- More distance
- More duration
- Better pace at the same effort
- More quality work
- Longer controlled efforts

---

# 11. Phase Transition

A phase should change when the current emphasis is no longer the best use
of training resources.

Possible reasons:

- Goal achieved
- Progress stalled
- New priority
- Excessive fatigue
- Upcoming event
- User preference changed
- Body composition target reached
- Endurance capability established

---

# 12. Phase Completion Evaluation

At the end of a phase, evaluate:

### Strength

- Exercise performance
- Repetitions
- Resistance
- Movement quality

### Running

- Weekly consistency
- Pace at comparable effort
- Longest recent run
- RPE
- Recovery

### Body composition

- Bodyweight trend
- Waist trend
- Visual changes if tracked

### Recovery

- Sleep
- Energy
- Soreness
- Fatigue
- Pain

### Adherence

- Sessions completed
- Missed sessions
- Training consistency

---

# 13. Phase Outcome Categories

The agent can classify the outcome as:

### Progress

The current approach is working.

Continue or gradually progress.

### Maintain

The goal is being preserved successfully.

Continue if the current emphasis remains appropriate.

### Adjust

Some progress exists but the approach needs modification.

### Deload

Fatigue is limiting productive training.

Reduce training stress temporarily.

### Change Emphasis

The current priority is no longer the most important objective.

Move into another phase.

---

# 14. Deloading

A deload is a temporary reduction in training stress.

It is not a mandatory event every fourth week.

The need for a deload should come from evidence such as:

- Accumulated fatigue
- Repeated performance decline
- Poor recovery
- Persistent soreness
- Reduced motivation
- Increasing training difficulty

A deload can involve reducing:

- Volume
- Intensity
- Exercise difficulty
- Running distance
- Running intensity

The exact adjustment depends on what is causing fatigue.

---

# 15. Deload vs Rest

A deload does not necessarily mean complete rest.

If the user is healthy but fatigued, lower training stress may be enough.

If illness or significant pain is present, the appropriate response may be
different.

The agent should distinguish training fatigue from situations requiring
medical evaluation or full rest.

---

# 16. No Automatic Deload Calendar

The agent should not blindly apply:

"3 weeks training + 1 week deload"

unless the user's actual response supports it.

Some phases may require longer uninterrupted progression.

Others may require earlier fatigue management.

---

# 17. Periodization and Running

Running can also be periodized.

A long-term sequence could be:

General fitness
→ aerobic base
→ endurance development
→ half-marathon capability
→ maintenance
→ strength emphasis

The user does not need to remain in half-marathon preparation forever.

---

# 18. Periodization and Strength

Strength training can also change emphasis.

Possible progression:

General movement proficiency
→ hypertrophy
→ strength development
→ consolidation
→ hypertrophy or another goal

The exact sequence depends on the user's training age and goals.

---

# 19. Beginner Training

The user is still developing foundational strength.

Therefore, the system should not overcomplicate periodization.

Early training should prioritize:

- Consistency
- Technique
- Exercise proficiency
- Progressive overload
- Recovery
- Basic work capacity

Complex advanced periodization is unnecessary if simple progression is
still producing results.

---

# 20. Periodization and Exercise Selection

Exercise selection can change between phases, but exercises should not be
changed constantly.

Frequent unnecessary variation makes progression harder to measure.

The agent should keep productive movements stable long enough to evaluate
progress.

Change an exercise when there is a reason.

---

# 21. Periodization and Nutrition

Nutrition should support the current phase.

### Strength/hypertrophy emphasis

Calories may be at maintenance or a modest surplus depending on the
specific goal.

### Body-composition emphasis

A moderate deficit may be appropriate.

### Endurance emphasis

Adequate carbohydrate and energy availability become increasingly
important.

### Maintenance

Calories can be adjusted to maintain body composition and performance.

The agent should not use one calorie strategy permanently.

---

# 22. Periodization and Recovery

Higher training emphasis requires more recovery resources.

The agent should consider:

- Sleep
- Nutrition
- Stress
- Total training load
- Running volume
- Strength volume

A phase that cannot be recovered from is poorly designed regardless of
how theoretically effective it looks.

---

# 23. Phase Changes Should Be Evidence-Based

The agent should avoid changing the program simply because the user is
bored for one day.

Likewise, it should not keep a phase indefinitely when objective progress
has stopped.

Use:

- Performance trends
- Recovery trends
- Goal status
- Adherence
- User preference

to make the decision.

---

# 24. Handling Plateaus

A plateau does not automatically mean the phase is finished.

First check:

- Was training actually consistent?
- Was progressive overload attempted?
- Is recovery adequate?
- Is nutrition appropriate?
- Is technique stable?
- Is the measurement reliable?
- Is fatigue masking performance?

Only after investigating should the agent make a major change.

---

# 25. Handling Rapid Progress

Rapid progress does not mean the agent should immediately multiply
training volume.

If the user is progressing well:

- Continue.
- Make small adjustments.
- Avoid unnecessary complexity.

The best program is often the one that keeps working.

---

# 26. Long-Term Cycling

A possible long-term pattern is:

**Strength emphasis**
→ **Body-composition adjustment**
→ **Endurance emphasis**
→ **Consolidation**
→ **Strength emphasis**

This is an example, not a mandatory sequence.

The actual order should follow the user's priorities.

---

# 27. Adaptive Periodization

The agent should continuously ask:

1. What is the current primary goal?
2. What phase are we in?
3. Is the phase producing the intended adaptation?
4. Is the user recovering?
5. Is the secondary goal being maintained?
6. Has a new priority appeared?
7. Is a phase transition justified?

This creates dynamic periodization rather than a fixed calendar.

---

# 28. Decision Rules

### If the current phase is producing progress + recovery is good:

Continue.

### If progress slows:

Investigate before changing the entire phase.

### If fatigue accumulates:

Reduce training stress or deload.

### If the primary goal changes:

Change phase emphasis.

### If the target adaptation is achieved:

Consider moving to maintenance or another priority.

### If secondary qualities decline excessively:

Adjust their maintenance volume.

### If training becomes unnecessarily complex:

Simplify.

---

# 29. Core Principle

Periodization is not about creating complicated schedules.

It is about deciding **what deserves the most training resources right
now**.

The agent should maintain useful fitness across multiple qualities while
periodically shifting emphasis toward the adaptation that matters most.

**Do not maximize everything at once. Prioritize, progress, maintain,
then shift when the evidence says it is time.**
