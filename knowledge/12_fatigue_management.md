# Fatigue Management

## Purpose

Fatigue management is the process of controlling training stress so the
user can continue producing useful adaptations without accumulating
unnecessary fatigue.

The goal is not to eliminate fatigue.

The goal is to keep fatigue at a level that allows:

- Consistent training
- Progressive overload
- Good technique
- Useful running performance
- Adequate recovery
- Long-term adherence

---

# 1. Fatigue Is Normal

Training creates fatigue.

Some fatigue is expected and useful.

Examples:

- Muscles feeling tired after training
- Temporary reduction in performance
- Increased appetite
- Mild soreness
- Heavy legs after a long run

These do not automatically indicate a problem.

The important question is whether fatigue is interfering with adaptation
and future training.

---

# 2. Fatigue vs Adaptation

Training causes both:

**Stimulus + fatigue**

The goal is to create enough stimulus to improve while keeping fatigue
manageable.

A session that creates enormous fatigue is not automatically a better
session.

The agent should prioritize:

**Stimulus-to-fatigue ratio**

---

# 3. Local Fatigue

Local fatigue affects specific muscles or tissues.

Examples:

- Chest fatigue after push-ups
- Back fatigue after rows
- Quadriceps fatigue after split squats
- Calf fatigue after running

Local fatigue should influence exercise selection and scheduling.

---

# 4. Systemic Fatigue

Systemic fatigue affects broader training capacity.

Possible signs:

- General tiredness
- Poor motivation
- Poor sleep
- Reduced performance across multiple exercises
- Running feels harder than usual
- Reduced recovery
- Persistent heaviness

Systemic fatigue should be considered when multiple training qualities
decline simultaneously.

---

# 5. Acute Fatigue

Acute fatigue is short-term fatigue caused by recent training.

Examples:

- Tired legs after a long run
- Reduced repetitions immediately after a hard workout
- Temporary soreness

Acute fatigue is expected.

The agent should not overreact to normal short-term fatigue.

---

# 6. Accumulated Fatigue

Fatigue can accumulate when training stress repeatedly exceeds recovery
capacity.

Possible contributors:

- High training volume
- High intensity
- Frequent hard sessions
- Increased running mileage
- Poor sleep
- Calorie restriction
- Life stress
- Illness

The agent should look for patterns rather than relying on one symptom.

---

# 7. Performance Trend

Performance is one of the strongest practical signals.

Potential warning pattern:

Normal performance
→ slightly worse
→ worse again
→ repeated difficulty

This is more meaningful than one bad session.

The agent should compare performance under similar conditions whenever
possible.

---

# 8. RPE Trend

The same workload becoming harder can indicate accumulating fatigue.

Example:

A familiar exercise normally feels like RPE 7.

If the same workload repeatedly feels like RPE 9, investigate:

- Recovery
- Sleep
- Nutrition
- Recent training
- Illness
- Stress

The agent should not automatically assume loss of fitness.

---

# 9. RIR Trend

Strength training can also reveal fatigue through RIR.

If the user normally performs:

10 reps @ 2 RIR

but suddenly struggles to achieve:

7 reps @ 0–1 RIR

at the same resistance, fatigue may be contributing.

One session is not enough evidence.

Repeated deterioration matters more.

---

# 10. Running Fatigue

Running fatigue may appear as:

- Easy pace feeling unusually difficult
- Higher RPE at normal pace
- Elevated heart rate at comparable effort
- Heavy legs
- Reduced ability to complete quality intervals
- Poor long-run recovery

The agent should evaluate recent running and strength load together.

---

# 11. Lower-Body Fatigue

Lower-body fatigue is particularly important because the user runs and
performs lower-body strength training.

Potential sources include:

- Squats
- Split squats
- Lunges
- Hip hinges
- Calf training
- Intervals
- Long runs
- Hills

The agent should avoid treating these as independent stressors.

They all consume lower-body recovery capacity.

---

# 12. Upper-Body Fatigue

Upper-body fatigue is generally less relevant to running but still affects
strength performance.

If upper-body performance repeatedly declines, investigate:

- Training volume
- Exercise overlap
- Sleep
- Nutrition
- Recovery

---

# 13. Fatigue Monitoring

Useful daily inputs include:

- Sleep duration
- Sleep quality
- Energy
- Soreness
- Motivation
- Pain
- Resting HR when available
- Training RPE
- Training performance

Not every metric needs to be collected every day.

The system should prioritize information that actually changes
decisions.

---

# 14. Simple Daily Readiness

The agent can ask the user for a quick status:

### Sleep

1–5

### Energy

1–5

### Soreness

1–5

### Motivation

1–5

### Pain

None / Mild / Moderate / Severe

### General readiness

Low / Moderate / Good

These inputs are useful as context, not as a scientifically exact
readiness score.

---

# 15. Training Response

After each session, the user should ideally report:

- What was performed
- Load/resistance
- Repetitions
- Sets
- RIR
- RPE
- Pain
- How difficult it felt
- Any unusual symptoms

For running:

- Distance
- Duration
- Pace
- HR if available
- RPE
- Pain
- Recovery afterward

This allows the agent to adapt future training.

---

# 16. When to Train Normally

Normal training is appropriate when:

- Recovery is generally good
- Performance is stable
- No concerning pain exists
- Sleep is acceptable
- Fatigue is manageable
- Recent training load is tolerated

The user does not need to feel 100% fresh before every session.

---

# 17. When to Modify Training

Modify the session when:

- Energy is lower than normal
- Sleep was poor
- Mild soreness remains
- Performance is slightly reduced
- Recent training load was unusually high

Possible modifications:

- Reduce sets
- Reduce reps
- Increase RIR
- Reduce resistance
- Use an easier exercise variation
- Reduce running distance
- Remove intervals
- Convert a quality run to an easy run

The goal is to preserve useful training while reducing unnecessary
fatigue.

---

# 18. When to Reduce Training Significantly

Significant reduction may be appropriate when:

- Multiple sessions show declining performance
- Fatigue persists for several days
- Recovery is consistently poor
- Sleep is repeatedly poor
- Running becomes unusually difficult
- Strength performance drops across multiple movements
- Motivation is persistently low

The agent should reduce training stress rather than forcing progression.

---

# 19. When to Rest

Rest or recovery-focused activity may be appropriate when:

- The user is clearly unable to train productively
- Significant fatigue is present
- Illness is present
- Pain makes normal movement difficult
- Recovery has not caught up with previous training

Rest is not failure.

It is a training decision when additional stress would have little
productive value.

---

# 20. Pain Override

Pain should override normal progression rules when appropriate.

The agent should distinguish:

### Low-level normal training discomfort

Temporary muscle fatigue or mild soreness.

### Concerning pain

- Sharp pain
- Increasing pain
- Persistent joint/tendon pain
- Pain changing movement
- Significant swelling
- Loss of function

The second category requires caution and may require professional
assessment.

The agent must not diagnose injuries.

---

# 21. Fatigue and Progressive Overload

Progression should depend on recovery.

If the user completes the target workload comfortably and recovery is
good:

Progression can be considered.

If the user barely completes the workload and recovery is poor:

Do not force progression.

---

# 22. Fatigue and RIR

When fatigued, increasing RIR can be useful.

Example:

Normal:

3 × 8–12 @ 2 RIR

Fatigued:

3 × 8–12 @ 3–4 RIR

or fewer sets.

This maintains movement practice while reducing stress.

---

# 23. Fatigue and Volume

Volume is often one of the simplest variables to reduce.

If the user is fatigued, the agent can reduce:

- Number of sets
- Running distance
- Number of intervals
- Long-run duration

Intensity does not always need to be eliminated.

The correct adjustment depends on the source of fatigue.

---

# 24. Fatigue and Intensity

High-intensity sessions can be disproportionately demanding.

When fatigue is high, the agent should be cautious with:

- Failure training
- Maximal strength efforts
- Hard intervals
- Sprinting
- Very demanding long runs

The objective is to avoid turning temporary fatigue into a larger
recovery problem.

---

# 25. Training Density

Training density means doing more work in less time.

Increasing density can increase fatigue even when total sets or distance
remain unchanged.

Therefore, the agent should consider:

- Rest periods
- Session duration
- Supersetting
- Running recovery intervals

Density should not be increased simply to make workouts harder.

---

# 26. Weekly Fatigue

The agent should consider the entire week.

Example:

Monday: hard strength  
Tuesday: quality run  
Wednesday: strength  
Thursday: long run  
Friday: hard strength  
Saturday: intervals

Even if every individual workout is reasonable, the combination may be
too demanding.

The weekly structure matters.

---

# 27. Fatigue and Concurrent Training

The user has two major training systems:

**Strength + Running**

The agent should calculate the practical interaction between them.

Examples:

- Hard split-squat session + intervals = high lower-body stress
- Long run + heavy hinge work = high posterior-chain stress
- Upper-body session + easy run = generally lower direct interference

This should influence scheduling.

---

# 28. Fatigue From Life Stress

Training is not the only source of stress.

The agent should consider:

- Academic workload
- Job/internship workload
- Poor sleep
- Travel
- Emotional stress
- Reduced food availability
- Changes in daily activity

When life stress increases significantly, training may need temporary
adjustment.

---

# 29. Fatigue During a Calorie Deficit

A calorie deficit reduces available recovery resources.

If the user is dieting while performing:

- 3 strength sessions
- 3 running sessions

the agent should monitor fatigue closely.

If performance consistently declines, possible solutions include:

- Reduce training stress
- Reduce calorie deficit
- Improve carbohydrate intake
- Improve sleep
- Add recovery

Do not simply push harder.

---

# 30. Deload

A deload is appropriate when accumulated fatigue is interfering with
productive training.

Possible methods:

- Reduce sets
- Reduce running distance
- Remove hard intervals
- Increase RIR
- Use easier exercise variations
- Reduce training frequency temporarily

The exact approach should match the source of fatigue.

---

# 31. Deload Duration

There is no universal required duration.

The agent should use the shortest reduction that restores useful
training quality.

After the deload, training should resume progressively rather than
immediately jumping to maximal workload.

---

# 32. Recovery After a Deload

Signs that recovery is improving may include:

- Better sleep
- Higher energy
- Improved motivation
- Normalized RPE
- Better training performance
- Reduced soreness
- Easier running

The agent can gradually restore training stress.

---

# 33. Fatigue Does Not Always Mean Deload

A difficult workout can create fatigue without requiring a deload.

For example:

One hard leg session
→ normal soreness
→ next session performed normally

is not a deload situation.

The agent should avoid unnecessary reductions in training.

---

# 34. Avoiding the "More Is Better" Trap

If progress slows, the first response should not automatically be:

- More sets
- More running
- More intensity
- More exercises
- More sessions

First investigate:

- Recovery
- Technique
- Nutrition
- Adherence
- Current workload
- Goal alignment

More training is useful only when the user can recover from it.

---

# 35. Fatigue and Missed Sessions

If the user misses a session because of fatigue:

Do not automatically make up the missed workload.

The agent should reassess the next session based on the current state.

Cramming missed workouts together can create unnecessary fatigue.

---

# 36. Fatigue Trend Categories

The agent can internally classify fatigue as:

### Normal

Expected training fatigue with stable performance.

### Elevated

Some warning signs but training remains productive.

### Accumulating

Multiple warning signals and declining performance.

### Excessive

Training quality is significantly compromised or pain/illness is
present.

These categories are decision aids, not medical diagnoses.

---

# 37. Decision Rules

### If performance is stable + recovery is good:

Train normally and progress when appropriate.

### If performance is stable + mild fatigue exists:

Train, but avoid unnecessary progression.

### If performance is slightly reduced:

Modify the session if needed.

### If performance declines repeatedly:

Reduce training stress and investigate.

### If multiple recovery signals deteriorate:

Prioritize recovery.

### If pain is worsening:

Stop normal progression and assess the issue.

### If illness is present:

Prioritize recovery and appropriate medical guidance.

### If fatigue resolves:

Gradually return to normal training.

---

# 38. Core Principle

Fatigue management is about protecting the user's ability to train
tomorrow, next week, and next year.

The correct response to fatigue is not always rest.

It may be:

- Maintain
- Reduce volume
- Increase RIR
- Slow the run
- Remove intensity
- Reschedule
- Deload
- Rest

The agent should choose the **smallest effective adjustment** that keeps
training productive.

**Do not chase maximum fatigue. Chase maximum sustainable adaptation.**
