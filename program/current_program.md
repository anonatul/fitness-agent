# Strength Programming Principles

Strength sessions should generally:

- Train major movement patterns
- Use manageable volume
- Stay mostly around 1–3 RIR
- Prioritize progression
- Avoid unnecessary failure
- Use stable exercises long enough to measure progress
- Account for running fatigue

Rest periods should be long enough to preserve performance.

As a general starting point:

- Compound movements: ~2–3+ minutes
- Isolation/accessory movements: ~1–2 minutes

Adjust based on exercise difficulty and recovery.

# Running Structure

## Run 1 — Easy Aerobic

### Purpose

Build aerobic capacity while keeping fatigue manageable.

### Default

**Distance:** ~4–5 km

### Intensity

Conversational.

Use:

- Talk test
- RPE
- Pace
- HR when available

Do not force a specific pace.

---

# Run 2 — Quality

### Purpose

Develop controlled higher-intensity running ability.

### Default Session

**Warm-up**

10 minutes easy.

**Main set**

4 × 3 minutes comfortably hard

with:

2 minutes easy recovery between repetitions.

**Cooldown**

5–10 minutes easy.

### Intensity

Hard enough to require concentration but controlled enough to repeat all intervals.

This should not become an all-out sprint session.

---

# Run 3 — Long Easy

### Purpose

Build endurance and prepare the body for future longer-distance running.

### Initial Range

Approximately **5–7 km**.

### Intensity

Easy conversational effort.

The long run should not routinely become a race.

---

# Running Progression

Do not automatically increase distance every week.

Progress based on:

- Current recovery
- Previous running volume
- RPE
- Pain
- Sleep
- Strength performance
- Running consistency

Possible progression methods:

- Slightly longer easy run
- Slightly longer long run
- Additional easy volume
- Improved quality-session control
- Improved pace at similar effort

Do not increase multiple major running variables aggressively at once.

---

# Weekly Training Stress

The program contains six training exposures:

- 3 resistance sessions
- 3 running sessions

This is intentionally demanding for a beginner.

The agent must monitor whether the user can recover from the combination.

If fatigue accumulates, the solution is not automatically "try harder."

Possible adjustments include:

- Reduce running intensity
- Reduce running volume
- Reduce strength accessory volume
- Increase recovery
- Temporarily reduce training frequency

---

# Session Ordering

The default ordering separates major strength and running stress.

However, the agent may rearrange sessions when:

- A session is missed
- Schedule changes
- Lower-body fatigue is high
- A quality run needs protection
- Strength progression needs protection
- Recovery is poor

The agent should avoid placing multiple high-fatigue lower-body sessions together unnecessarily.

---

# Warm-Up

Warm-ups should be brief and specific.

Typical structure:

1. General movement
2. Joint/movement preparation
3. Exercise-specific warm-up
4. First working set

Avoid turning the warm-up into an additional workout.

---

# Cooldown

Cooldown is optional after strength training.

After harder running, several minutes of easy movement may be useful.

The cooldown is not required to prevent soreness.

---

# Current Program Is Not Permanent

This program is the current starting structure.

The agent should modify it when evidence indicates that the current setup is:

- Too easy
- Too difficult
- Too fatiguing
- Not progressing
- Causing pain
- Poorly matched to schedule
- Poorly matched to current goals

---

# Beginner Calibration

The first phase should be treated partly as a calibration period.

The agent needs to learn:

- Actual strength capacity
- RIR accuracy
- Recovery capacity
- Running tolerance
- Lower-body fatigue response
- Appropriate weekly volume
- Exercise suitability

Do not make aggressive programming changes based on the first few sessions.

# Program Modification Hierarchy

When the current program needs adjustment:

1. Protect safety
2. Protect the current primary goal
3. Reduce unnecessary fatigue
4. Preserve useful training frequency
5. Modify volume/intensity
6. Modify exercise selection
7. Reorganize weekly schedule
8. Change the training phase only if necessary

Do not change the entire program because of one mediocre session.

# Core Principle

**This program is a starting template, not a contract. The agent's job is to continuously adapt it to the user's actual performance, recovery, goals, and constraints while preserving the underlying training principles.**
