# Progression Rules

## Purpose

This file defines how the training agent should decide when and how to increase training difficulty.

Progression should be **earned through performance and recovery**, not forced because a new week has started.

---

# Core Progression Principle

Training should become gradually more demanding over time when the user can recover from the current workload.

Progression can occur through:

- More repetitions
- More resistance
- More sets
- Harder exercise variation
- Less assistance
- Greater range of motion
- Better execution
- Greater running distance
- Greater running duration
- Better performance at similar effort

Do not increase every variable simultaneously.

---

# Strength Progression

## Primary Method: Double Progression

For exercises with a rep range:

1. Keep resistance and variation stable.
2. Gradually increase repetitions.
3. Maintain appropriate RIR.
4. Once the upper end of the rep range is reached with good technique, increase difficulty.
5. Return toward the lower end of the range.
6. Repeat.

Example:

3 × 6–10

Possible progression:

- 8, 8, 7
- 9, 8, 8
- 10, 9, 9
- 10, 10, 10

Once 10 reps can be performed across all sets with appropriate RIR and good technique, increase resistance or exercise difficulty.

---

# RIR-Based Progression

Progression should consider both repetitions and effort.

Example:

A user performs:

- 10 reps @ 3 RIR

This is not necessarily equivalent to:

- 10 reps @ 1 RIR

The agent should consider whether the target stimulus and effort were achieved.

---

# When to Progress

Progress when most of the following are true:

- Target reps are being achieved
- Technique is stable
- RIR is within the intended range
- Recovery is acceptable
- No meaningful pain is present
- Performance has been stable or improving
- Current difficulty is no longer sufficiently challenging

Progression may involve only one small change.

---

# When NOT to Progress

Do not increase difficulty when:

- Technique is deteriorating
- RIR is already lower than intended
- Recovery is poor
- Performance is falling across multiple sessions
- Significant soreness is interfering with training
- Pain is present
- Running fatigue is unusually high
- Life stress is significantly affecting recovery
- Current volume is already excessive

---

# Repetition Progression

Increase repetitions when:

- The exercise is technically stable
- The user remains within the target RIR
- The upper end of the range has not yet been reached

Do not add reps simply to make the workout harder.

---

# Resistance Progression

Increase resistance when:

- The current rep target is consistently achievable
- Technique remains strong
- The user has sufficient recovery
- The next resistance level is practical

For backpack exercises, increase load gradually.

For bands, progression may involve:

- Stronger band
- Additional band
- Increased stretch
- Different setup

Band resistance is not perfectly measurable, so consistency of setup is important.

---

# Exercise Difficulty Progression

When external loading cannot easily be increased, use a harder variation.

Example:

Incline push-up  
→ Lower incline  
→ Standard push-up  
→ Feet-elevated push-up  
→ More difficult variation

The agent should choose progressions that remain technically appropriate.

---

# Pull-Up / Chin-Up Progression

Current baseline:

- Pull-up: approximately 0 strict reps
- Chin-up: approximately 0 strict reps

Progression hierarchy:

1. Scapular control
2. Assisted repetitions
3. Reduced assistance
4. Controlled eccentrics
5. Isometric holds
6. Partial-to-full ROM
7. First strict repetition
8. Multiple strict repetitions
9. Added resistance eventually

Do not force strict repetitions before the user has sufficient control.

---

# Bodyweight Exercise Progression

For bodyweight exercises, progression can use:

- Reps
- ROM
- Exercise angle
- Leverage
- Tempo
- Pauses
- External load
- Harder variation

Prefer external resistance or meaningful variation over endlessly increasing repetitions once very high rep counts are reached.

---

# Lower-Body Progression

Lower-body progression must account for running.

Before increasing lower-body strength volume or load, consider:

- Recent runs
- Long-run distance
- Quality running
- Leg soreness
- Shin/lower-leg symptoms
- Overall recovery

Do not increase lower-body training aggressively while simultaneously increasing running load.

---

# Running Progression

Running progression should prioritize **load tolerance** before speed.

Possible progression order:

1. Consistent frequency
2. Consistent easy running
3. Gradually increased easy volume
4. Gradually increased long-run duration/distance
5. More controlled quality work
6. Improved pace at similar effort
7. Greater race-specific endurance when appropriate

This is not a mandatory sequence.

---

# Easy Run Progression

An easy run can progress through:

- Slightly longer distance
- Slightly longer duration
- Improved pace at the same perceived effort

The defining feature remains easy intensity.

If pace increases but effort also increases substantially, that is not necessarily aerobic progression.

---

# Long-Run Progression

Increase long-run duration or distance gradually.

Before progressing, consider:

- Previous long run
- Total weekly running volume
- Recovery
- Lower-leg condition
- Strength performance
- Life stress

Do not automatically increase the long run every week.

---

# Quality-Run Progression

Quality running can progress through:

- More controlled repetitions
- Slightly longer intervals
- More total quality time
- Slightly shorter recoveries
- Faster pace at similar effort

Only one major variable should normally change at a time.

Quality running should remain controlled rather than becoming maximal.

---

# Concurrent Progression

Because the user performs both strength and running, progression must consider total training stress.

Example:

If running volume increases substantially, strength progression may temporarily remain stable.

If strength training is progressing aggressively, running may remain at maintenance volume.

The agent should not assume that every component needs to improve simultaneously.

---

# Volume Progression

Increase volume only when:

- Current volume is recoverable
- Performance has room to improve
- The user is adapting
- Additional volume is likely to provide useful stimulus

More volume is not automatically better.

If performance improves with current volume, there may be no reason to add more.

---

# Intensity Progression

Intensity can increase through:

- More external resistance
- Harder exercise variation
- Faster running
- Higher-quality intervals

Do not increase intensity merely because the user feels motivated.

---

# Density Progression

Training density means performing similar work in less time.

Density should not be a primary progression method for strength/hypertrophy unless it does not reduce performance.

Shortening rest periods can increase fatigue without increasing the useful stimulus.

For strength work, preserve sufficient rest.

---

# Technique Progression

Technique improvement counts as meaningful progress.

Examples:

- Better ROM
- More controlled eccentric
- Better stability
- Less compensatory movement
- Better consistency

Do not automatically increase load when technique is still improving.

---

# Plateau Rules

A plateau is not one bad workout.

Consider a plateau when:

- Performance repeatedly fails to improve
- The same exercise has stalled across multiple exposures
- Recovery is adequate
- Nutrition is adequate
- Technique is stable
- Progression has been attempted appropriately

Before changing the exercise, check:

1. Recovery
2. Nutrition
3. RIR accuracy
4. Volume
5. Exercise technique
6. Recent running fatigue
7. Life stress

Then modify the smallest useful variable.

---

# Progression During Fatigue

When fatigue is temporarily elevated:

- Maintain resistance
- Maintain reps
- Reduce volume
- Increase recovery
- Reduce running intensity
- Use easier variations if necessary

Progression can resume once recovery improves.

---

# Progression During a Deload

Do not chase progression during a deload.

The purpose is to reduce accumulated fatigue while maintaining movement patterns.

Return to progression after normal training resumes.

---

# Progression After a Break

After a meaningful training interruption:

- Reduce difficulty temporarily
- Rebuild technique
- Avoid immediately matching previous peak workload
- Monitor soreness
- Monitor pain
- Rebuild volume before aggressively increasing intensity

The length and severity of the break determine how much adjustment is required.

---

# Progression After Missed Sessions

Never compensate for missed sessions by doubling volume automatically.

Instead:

1. Review the last completed session.
2. Review upcoming sessions.
3. Determine current recovery.
4. Select the next useful training exposure.
5. Continue progression from the new sequence.

---

# Progression and Pain

Pain overrides progression.

If a movement causes meaningful pain:

- Do not increase its difficulty
- Modify the movement
- Reduce load or ROM if appropriate
- Substitute when necessary
- Monitor symptoms

Persistent or worsening pain should be assessed professionally.

---

# Progression Across Training Phases

Progression strategy changes with the phase.

### Strength/H hypertrophy emphasis

Prioritize:

- Resistance
- Repetitions
- Sets
- Exercise difficulty

### Endurance emphasis

Prioritize:

- Running volume
- Long-run development
- Aerobic workload
- Specific endurance

### Maintenance phase

Prioritize:

- Minimum effective workload
- Skill retention
- Strength retention
- Aerobic retention

### Body-composition emphasis

Prioritize:

- Muscle retention
- Training quality
- Sustainable energy deficit
- Recovery

---

# Progression Decision Sequence

Before increasing training demand, ask:

1. Is the user healthy enough to train?
2. Is the current goal still the priority?
3. Was the previous workload completed successfully?
4. Was technique acceptable?
5. Was effort appropriate?
6. Is recovery adequate?
7. Is pain absent or acceptable?
8. Is additional stress useful?
9. Which single progression variable provides the best benefit?
10. Can the user realistically recover from it?

Only then progress.

---

# Progression Is Not Linear

Progress may look like:

> progress → progress → maintain → progress → small regression → progress

This is normal.

The agent should evaluate trends rather than expecting uninterrupted improvement.

---

# Core Principle

**Progress training when the current workload is no longer sufficiently challenging and the user can recover from additional stress. Progress should be small, measurable, and sustainable—not forced.**
