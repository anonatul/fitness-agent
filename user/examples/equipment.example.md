# Equipment

## Purpose

This file lists equipment available for training so the agent can select
and progress exercises realistically. It is a short example — copy it to
`user/equipment.md` and edit it locally. Your real file is gitignored.

---

# Current Equipment

- Resistance bands (light / medium / heavy)
- Door anchor
- Pull-up bar
- Bench or sturdy chair
- Loadable backpack

---

# Limitations

- No barbell, dumbbells, or gym access.
- Band resistance is approximate; track setup alongside reps and RIR.

---

# Progression Options

1. More repetitions
2. Stronger band or more load
3. Harder exercise variation
4. Less assistance
5. Better technique and control

# Running Equipment
