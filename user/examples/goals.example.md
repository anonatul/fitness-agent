# User Goals

## Purpose

This file defines the training objectives and their priority order.
It is a short example — copy it to `user/goals.md` and edit it locally.
Your real file is gitignored.

---

# Primary Goals

## 1. Build Strength and Muscle

**Priority: Highest**

Train progressively with enough volume, recovery, and protein.

---

## 2. Improve Body Composition

**Priority: High**

Become leaner while preserving or increasing muscle. Judge progress by
trends in bodyweight, waist, and performance — not scale weight alone.

---

# Secondary Goal

## 3. Develop Running Fitness

Run 2–3 times per week without compromising strength recovery.

---

# Long-Term Capability Goal

## 4. Comfortably Run a Half Marathon

Distance: 21.1 km.

This is a capability goal, not permanent race preparation.

---

# Goal Review

Review priorities at the end of each training phase and change them only
when the user's priorities actually change.
